# منصة المكتبة الإلكترونية

منصة ويب عربية (RTL) لمكتبة مؤسسة تعليمية: مصادر إلكترونية، كتب، طلبات استعارة بدون أي دفع، مشاريع وفعاليات مع تنبيهات تلقائية، استبيانات، استطلاع زيارة المكتبة، ولوحة تحكم بإحصائيات منفصلة لكل خدمة وإدارة كاملة للمحتوى.

**مبدأ الخصوصية:** بيانات الطالبات الشخصية (الاسم، الرقم التدريبي، البريد، الجوال) لا تُحفظ في قاعدة بيانات الموقع. تذهب مباشرة إلى نماذج Microsoft Forms (أو تدفق Power Automate) في حساب المؤسسة. الموقع يحفظ المحتوى العام وإحصائيات مجهولة الهوية فقط.

## التشغيل السريع (بيئة التطوير)

المتطلبات: **Node.js 22.13 أو أحدث**.

```bash
# 1) تثبيت الحزم
npm run install:all

# 2) إعداد ملف البيئة
cp .env.example .env
#   - ضعي قيمًا عشوائية في SESSION_SECRET و ANALYTICS_SALT:
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
#   - أنشئي تجزئة كلمة مرور المسؤولة (تُكتب كلمة المرور مخفية):
npm run hash-password --prefix server
#   - انسخي السطر الناتج ADMIN_PASSWORD_HASH=... إلى .env وحددي ADMIN_USERNAME

# 3) التشغيل (الخادم على 4000 والواجهة على 5173)
npm run dev
```

- الموقع: <http://localhost:5173>
- لوحة التحكم: <http://localhost:5173/admin>

عند أول تشغيل تُملأ قاعدة البيانات بمحتوى أولي (كتب ومصادر إلكترونية حقيقية معروفة، ومشاريع وفعاليات نموذجية)، وإذا كان `SEED_DEMO_ANALYTICS=true` تُضاف إحصائيات تجريبية معلَّمة لتوضيح الرسوم. احذفيها من **الإعدادات ← البيانات** قبل الإطلاق.

> يمكن أيضًا إنشاء حساب مسؤولة من الطرفية: `npm run create-admin --prefix server`

## التشغيل في بيئة الإنتاج

```bash
npm run build          # بناء الخادم والواجهة
NODE_ENV=production npm start
```

في الإنتاج يخدم الخادم ملفات الواجهة من `client/dist` على نفس المنفذ. يجب:

- ضبط `SESSION_SECRET` و `ANALYTICS_SALT` (32 حرفًا على الأقل) — يرفض الخادم التشغيل بدونهما.
- تشغيل الموقع خلف **HTTPS** (مثل Nginx أو IIS كوكيل عكسي). ملفات تعريف الارتباط آمنة افتراضيًا.
- وضع التجربة للنماذج (`FORMS_DEV_SINK`) يُعطَّل تلقائيًا في الإنتاج.
- أخذ نسخة احتياطية دورية من ملف قاعدة البيانات (`DATABASE_PATH`) ومجلد `server/uploads`.

## صفحات الموقع

| الصفحة | المسار | ملاحظات |
|---|---|---|
| الرئيسية | `/` | Hero، إحصائيات حيّة، الخدمات، الفعاليات القادمة، كتب متاحة |
| المصادر الإلكترونية | `/resources` | بحث + تصفية (التخصص، النوع، التصنيف)؛ تُسجَّل زيارة القسم وكل فتح لمصدر |
| الكتب | `/books` | بحث + تصفية (التصنيف، الحالة)؛ زر «استعارة الكتاب» |
| الاستعارة | `/borrow` و `/borrow/:id` | اختيار الكتاب ثم النموذج؛ اسم الكتاب ومؤلفه يُعبآن تلقائيًا |
| المشاريع | `/projects` | القادمة + المشاريع المقدمة + الفعاليات السابقة |
| الفعاليات | `/events` | القادمة/السابقة مع العد التنازلي المحسوب |
| الاستبيانات | `/surveys` | الحالة تُحسب من تاريخي البداية والنهاية |
| زيارة المكتبة | `/visit` | أسئلة شرطية (نعم ← معدل الزيارة، لا ← الأسباب) |

**التنبيهات:** شريط أعلى الموقع وجرس تنبيهات يعرضان نصوصًا مثل «متبقي 3 أيام على إقامة…» أو «فعالية قادمة غدًا»، محسوبة لحظيًا بتوقيت الرياض. بعد انتهاء الفعالية (وقت الانتهاء، أو ساعتان من البداية إن لم يُحدد) تنتقل تلقائيًا إلى السابقة.

## لوحة التحكم (`/admin`)

- **الرئيسية:** بطاقات المؤشرات التسعة + رسوم الزيارات اليومية والاستعارات والمصادر وأسباب عدم الزيارة + تنبيه الاستعارات المتأخرة.
- **الإحصائيات:** تبويب مستقل لكل خدمة (عام، المصادر، الكتب، الاستعارة، المشاريع، الاستبيانات، زيارة المكتبة) مع فترات 7/30/90/365 يومًا أو الكل. كل رسم يمكن عرضه كجدول.
- **الكتب / المصادر / المشاريع / الفعاليات / الاستبيانات:** إضافة وتعديل وحذف مع بحث وتصفية ورفع صور وملفات.
- **الاستعارات:** سجلات مجهولة (الرمز المرجعي، الكتاب، التخصص، التواريخ، الحالة). تغيير الحالة إلى «مستعار» يُنقص النسخ المتاحة، والإرجاع يعيدها. تصدير CSV.
- **الزوار:** زوار الموقع ونتائج استطلاع الزيارة.
- **الإعدادات:** بيانات المكتبة والشعار، ربط Microsoft Forms، القوائم (التخصصات والأنواع والجهات)، التصنيفات، المستخدمون والصلاحيات، البيانات التجريبية، تغيير كلمة المرور.

### الصلاحيات

| الدور | الصلاحيات |
|---|---|
| مسؤولة النظام (`admin`) | كل شيء |
| أمينة مكتبة (`librarian`) | المحتوى، الاستعارات، الإحصائيات — دون الإعدادات العامة والمستخدمين |

المستخدم العادي لا يحتاج حسابًا ولا يستطيع الوصول إلى `/api/admin`.

## ربط Microsoft Forms

راجعي الدليل التفصيلي: [`docs/MICROSOFT_FORMS.md`](docs/MICROSOFT_FORMS.md)

باختصار، لكل من نموذج الاستعارة واستطلاع الزيارة طريقتان تُختاران من **الإعدادات ← Microsoft Forms**:

1. **Microsoft Forms مباشرة (موصى به):** تملأ الطالبة النموذج في الموقع (مع التحقق)، يُحفظ الجزء المجهول للإحصائيات، ثم يُفتح النموذج الرسمي **معبأً مسبقًا** لتضغط «إرسال». البيانات الشخصية تنتقل من متصفحها إلى Microsoft مباشرة ولا تمر بالخادم.
2. **Power Automate:** يمرر الخادم النموذج الكامل إلى تدفق HTTP في حساب المؤسسة دون تخزينه. رابط التدفق سري ويوضع في `FLOW_URL_BORROW` / `FLOW_URL_VISIT` فقط.

الاستبيانات العامة تُربط برابط Microsoft Forms لكل استبيان من صفحة الاستبيانات. أي رابط من خارج نطاقات Microsoft Forms يُرفض.

إلى أن يتم الربط تظهر النماذج برسالة «غير متاح مؤقتًا» بدل أزرار وهمية.

```
├── .env.example              # كل الإعدادات الحساسة (بدون قيم)
├── docs/MICROSOFT_FORMS.md   # دليل الربط بحساب المؤسسة
├── scripts/dev.mjs           # تشغيل الخادم والواجهة معًا
├── server/src
│   ├── app.ts / index.ts     # إعداد Express والأمان
│   ├── config.ts             # قراءة متغيرات البيئة
│   ├── db/                   # الاتصال، المخطط (migrations)، البيانات الأولية
│   ├── repositories/         # طبقة التخزين (واجهات + تنفيذ SQLite)
│   ├── services/             # الإحصائيات، الاستعارات، النماذج، المصادقة، الإعدادات
│   ├── routes/               # public · forms · analytics · auth · admin
│   ├── schemas.ts            # قواعد التحقق (Zod)
│   └── tests/                # اختبارات التكامل
└── client/src
    ├── components/ui         # أزرار، حقول، نوافذ، شارات، حالات فارغة وتحميل
    ├── components/layout     # الترويسة، قائمة الجوال، التنبيهات، التذييل
    ├── components/public     # بطاقات الكتب والمصادر والمشاريع والفعاليات، النموذج الرسمي
    ├── components/admin      # الشريط الجانبي، الجداول المتجاوبة، مدير المحتوى، الرسوم
    ├── pages/public          # صفحات الموقع
    ├── pages/admin           # صفحات لوحة التحكم والإعدادات
    ├── lib                   # API، الإحصائيات، التنسيق والتواريخ، أدوات Forms، التحقق
    └── index.css             # الهوية البصرية (لوحة الألوان والتدرج)
```

### قاعدة البيانات

| الجدول | المحتوى |
|---|---|
| `books`, `electronic_resources`, `projects`, `events`, `surveys`, `categories` | المحتوى العام |
| `settings` | إعدادات الموقع (JSON) |
| `analytics_events` | أحداث استخدام مجهولة + معرّف زائر مُجزّأ يتغير يوميًا |
| `loans` | سجلات استعارة مجهولة (بدون أي بيانات تعريفية) |
| `visit_responses` | الجزء الإحصائي من استطلاع الزيارة |
| `users` | حسابات لوحة التحكم (كلمات المرور مجزّأة بـ scrypt) |

كل الوصول للبيانات يمر عبر `server/src/repositories`. لتغيير طريقة التخزين (PostgreSQL أو SharePoint Lists مثلًا) يكفي كتابة تنفيذ جديد لنفس الواجهات وتصديره من `repositories/index.ts` دون تعديل المسارات أو الواجهة.

## الأمان

- لا توجد كلمات مرور أو مفاتيح أو روابط تدفق داخل الكود؛ كلها في `.env` المستثنى من Git.
- الجلسات: JWT موقّع في ملف تعريف ارتباط `HttpOnly` + `SameSite=Strict`، مع ترويسة `X-Library-Client` لحماية إضافية من CSRF، وتُبطل الجلسات عند تغيير كلمة المرور أو الصلاحية.
- تحديد معدل الطلبات: محاولات الدخول الفاشلة (10 كل 15 دقيقة)، والنماذج والإحصائيات بحدود مرتفعة تناسب شبكة منشأة تجمع كثيرًا من الطالبات خلف عنوان IP واحد.
- ترويسات أمان عبر Helmet مع CSP يسمح بتضمين Microsoft Forms فقط.
- رفع الملفات: PNG/JPG/WEBP/PDF فقط، 5 ميجابايت، مع التحقق من توقيع الملف الفعلي.
- لا تُطبع أجسام الطلبات في السجلات.
