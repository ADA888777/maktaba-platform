# دليل ربط النماذج بحساب المؤسسة (Microsoft Forms)

الهدف: أن تصل بيانات الطالبات الشخصية إلى **حساب المؤسسة** (المقترح: `shouga@tvt.gov.sa`) وليس إلى الموقع أو حساب المطوّر.

الموقع **لا يسجّل الدخول** إلى حساب Microsoft ولا يحتفظ بكلمة مروره. صاحبة الحساب تنشئ النماذج بنفسها، ثم تضع روابطها في لوحة التحكم.

---

## ما الذي يُحفظ وأين؟

| البيانات | المكان |
|---|---|
| الاسم، الرقم التدريبي، البريد، الجوال، الملاحظات، الاقتراحات النصية | Microsoft Forms / Power Automate (حساب المؤسسة) فقط |
| الكتاب، التخصص، تاريخ الاستعارة والإرجاع، الرمز المرجعي | قاعدة بيانات الموقع (للإحصائيات وإدارة النسخ) |
| إجابات «هل زرت المكتبة؟»، الأسباب، الخدمة الأكثر استخدامًا | قاعدة بيانات الموقع (بدون الاسم) |
| الزيارات وفتح المصادر | قاعدة بيانات الموقع (أحداث مجهولة) |

**الرمز المرجعي** (مثل `LB-7KQ2MX`) يُعبأ في نموذج Microsoft Forms. بواسطته تطابق المسؤولة الرد في Forms مع السجل المجهول في صفحة «الاستعارات» وتحدّث حالته (مستعار/تم الإرجاع).

---

## الطريقة الأولى (موصى بها): Microsoft Forms مباشرة

### 1) إنشاء نموذج الاستعارة

سجّلي الدخول إلى <https://forms.office.com> بحساب المؤسسة، وأنشئي نموذجًا بالأسئلة التالية (يُفضّل أن تكون كلها **نصية** لتعمل التعبئة المسبقة بدقة):

| السؤال المقترح | النوع | اسم الحقل في الموقع |
|---|---|---|
| الرمز المرجعي للطلب | نص | `referenceCode` |
| اسم الكتاب | نص | `bookTitle` |
| مؤلف الكتاب | نص | `bookAuthor` |
| اسم الطالبة/المتدربة | نص (مطلوب) | `fullName` |
| الرقم التدريبي | نص (مطلوب) | `traineeId` |
| التخصص | نص | `specialty` |
| البريد الإلكتروني | نص | `email` |
| رقم الجوال | نص | `phone` |
| تاريخ الاستعارة | نص | `borrowDate` |
| التاريخ المتوقع للإرجاع | نص | `returnDate` |
| ملاحظات | نص طويل | `notes` |

من إعدادات النموذج: اجعليه متاحًا للأشخاص داخل المؤسسة فقط إن كانت الطالبات يملكن حسابات المؤسسة، أو «أي شخص يمكنه الرد» حسب سياسة المؤسسة.

### 2) توليد الرابط المعبأ مسبقًا

1. من قائمة «…» في أعلى النموذج اختاري **Get pre-filled URL** (الحصول على عنوان URL معبأ مسبقًا).
2. في كل سؤال اكتبي **اسم الحقل** من العمود الأخير كإجابة تجريبية (مثل `fullName`، `bookTitle`).
3. اضغطي «الحصول على الارتباط» وانسخيه.

> إذا لم يظهر الخيار، فقد تكون الميزة غير مفعّلة في المؤسسة؛ يمكن حينها استخدام رابط المشاركة العادي (تكتب الطالبة كل البيانات في النموذج الرسمي) أو الطريقة الثانية.

### 3) الربط في لوحة التحكم

1. **الإعدادات ← Microsoft Forms ← نموذج استعارة الكتب**.
2. اختاري «Microsoft Forms مباشرة».
3. الصقي الرابط في «الرابط المعبأ مسبقًا» واضغطي **تحليل الرابط** — تُربط الحقول تلقائيًا لأن الإجابات التجريبية هي أسماء الحقول.
4. راجعي جدول الربط، واختاري طريقة العرض (نافذة جديدة أو تضمين داخل الصفحة).
5. اضغطي «معاينة النموذج بقيم تجريبية» للتأكد (لا ترسليه)، ثم **حفظ الإعدادات**.

### 4) ماذا تشاهد الطالبة؟

1. تختار الكتاب وتملأ النموذج في الموقع (مع رسائل تحقق واضحة).
2. عند «متابعة إلى النموذج الرسمي» يُسجَّل الطلب المبدئي ويظهر الرمز المرجعي.
3. يُفتح نموذج المؤسسة ببياناتها معبأة؛ تراجعها وتضغط **إرسال** — يصلها تأكيد Microsoft Forms.

### استطلاع زيارة المكتبة

الأسئلة المقترحة (أسماء الحقول): `fullName`، `specialty`، `hasVisited` (القيمة «نعم» أو «لا»)، `visitFrequency`، `reasons` (الأسباب مفصولة بفاصلة)، `otherReason`، `mainService`، `otherService`، `suggestions`.

> أسئلة «الاختيار» في Forms تقبل التعبئة فقط إذا طابقت القيمة نص الخيار حرفيًا. الأسئلة متعددة الاختيارات (مثل الأسباب) الأفضل أن تكون **نصية**.

## الطريقة الثانية: Power Automate

مناسبة إذا رغبت المؤسسة أن ترسل الطالبة النموذج من الموقع مباشرة دون فتح Forms.

1. في <https://make.powerautomate.com> بحساب المؤسسة أنشئي تدفقًا فوريًا يبدأ بـ **When an HTTP request is received**.
2. استخدمي مخطط JSON التالي لنموذج الاستعارة:

```json
{
  "type": "object",
  "properties": {
    "form": { "type": "string" },
    "submittedAt": { "type": "string" },
    "referenceCode": { "type": "string" },
    "fullName": { "type": "string" },
    "traineeId": { "type": "string" },
    "specialty": { "type": "string" },
    "email": { "type": "string" },
    "phone": { "type": "string" },
    "bookTitle": { "type": "string" },
    "bookAuthor": { "type": "string" },
    "borrowDate": { "type": "string" },
    "returnDate": { "type": "string" },
    "notes": { "type": "string" }
  }
}
```

   ولاستطلاع الزيارة: `fullName`, `specialty`, `hasVisited`, `visitFrequency`, `reasons`, `otherReason`, `mainService`, `otherService`, `suggestions`.

3. أضيفي خطوة **Add a row into a table** (Excel في OneDrive/SharePoint المؤسسة) أو **Create item** (قائمة SharePoint).
4. أضيفي خطوة **Response** بحالة `200`.
5. احفظي التدفق وانسخي **HTTP POST URL**.
6. ضعي الرابط في ملف `.env` على الخادم:

```env
FLOW_URL_BORROW=https://...logic.azure.com/...
FLOW_URL_VISIT=https://...logic.azure.com/...
```

7. أعيدي تشغيل الخادم، ثم اختاري «Power Automate» من الإعدادات.

> رابط التدفق يحتوي توقيعًا سريًا يسمح لأي شخص يملكه بالإرسال؛ لذلك لا يظهر في الواجهة ولا يُحفظ في قاعدة البيانات.

الخادم يمرر البيانات إلى التدفق **في الذاكرة فقط** ولا يكتبها في أي ملف أو سجل. إن فشل الإرسال تظهر للطالبة رسالة خطأ ولا يُسجَّل الطلب.

---

## الاستبيانات العامة

1. أنشئي الاستبيان في Microsoft Forms بحساب المؤسسة.
2. من «جمع الردود» انسخي رابط المشاركة.
3. في لوحة التحكم ← **الاستبيانات** أضيفي الاستبيان بتاريخي البداية والنهاية والرابط.
4. يحسب الموقع «المشاركات من الموقع» (عدد مرات الضغط على زر المشاركة). العدد الفعلي للردود موجود في Forms، ويمكن إدخاله يدويًا في حقل «عدد الردود في Microsoft Forms» ليظهر في الإحصائيات.

---

## أسئلة شائعة

**هل يستطيع الموقع قراءة ردود Microsoft Forms؟**
لا. هذا مقصود لحماية البيانات؛ الردود تُراجع من حساب المؤسسة.

**كيف أعرف أن الطالبة أرسلت النموذج الرسمي فعلًا؟**
ابحثي عن الرمز المرجعي في ردود Forms. الطلبات التي بقيت «طلب جديد» دون رد مطابق يمكن تحويلها إلى «ملغي».

**هل الرابط المعبأ مسبقًا آمن؟**
البيانات تنتقل من متصفح الطالبة إلى Microsoft مباشرة عبر HTTPS ولا تمر بخادم الموقع. لكنها تظهر في شريط العنوان وسجل المتصفح على جهاز الطالبة؛ على الأجهزة المشتركة يُفضّل خيار «تضمين داخل الصفحة» أو طريقة Power Automate.
